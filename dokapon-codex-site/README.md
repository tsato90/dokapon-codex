# Dokapon Connect Codex

An unofficial fan reference for *Dokapon Kingdom: Connect*: gear, items, magic, shops, monsters, jobs, maps, story and strategy, read from the Steam build's game data.

The whole site is one self-contained page (`index.html`) with its images embedded, so there's nothing to build.

Game text and art belong to their owners (Sting / Idea Factory). This is a non-commercial fan project.
